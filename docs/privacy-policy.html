Privacy Policy

Last updated: April 2026

This Privacy Policy describes how the BTCPay Server for Clover app ("the App") handles information. The App is an open-source integration that connects Clover POS devices to a merchant's self-hosted BTCPay Server instance.

1. Information We Collect

The App stores the following information locally on the Clover device using Android SharedPreferences:

  • BTCPay Server URL
  • BTCPay Store ID
  • BTCPay API Key

This information is entered by the merchant during setup and is stored only on the device. It is never transmitted to any third party other than the merchant's own BTCPay Server.

2. Information We Do Not Collect

The App does not collect, store, or transmit:

  • Customer personal data
  • Payment card information
  • Transaction history
  • Location data
  • Device identifiers
  • Analytics or usage data

3. How the App Works

When a customer selects BTCPay Server as a payment method at checkout, the App communicates directly with the merchant's own BTCPay Server to create a payment invoice. All payment data is handled by the merchant's BTCPay Server. The App does not have access to any payment funds or customer data.

4. Third Party Services

The App connects only to the BTCPay Server instance configured by the merchant. No data is shared with any other third-party service, analytics platform, or advertising network.

5. Data Security

API credentials are stored locally on the Clover device and are only used to authenticate with the merchant's own BTCPay Server. We recommend merchants use API keys with minimum required permissions and rotate them regularly.

6. Open Source

This App is fully open source. The complete source code is available at https://github.com/TChukwuleta/btcpayserver-clover-app. Anyone can review how the App handles data.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date at the top of this page.

8. Contact

For questions about this Privacy Policy, please open an issue on the GitHub repository at https://github.com/TChukwuleta/btcpayserver-clover-app/issues.
